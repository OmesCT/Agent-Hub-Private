สรุปผลการปฏิบัติงานรายโปรเจกต์ (Overall Outcomes)

1. MFT-Pipeline มิ.ย. - ก.ย.

ระบบบริหารจัดการและปรับใช้การตั้งค่า IBM Sterling MFT แบบอัตโนมัติ (MFT-Pipeline-Project)

  • พัฒนา 4 Pipelines สำหรับ NPD (Build, Export, Import, Rollback) แยกโฟลเดอร์ release/ และ draft/
  • สร้าง Shared Library (mft-utils) 10 โมดูล แยกตรรกะธุรกิจออกจาก Jenkinsfile
  • ทำ Sanitize Credentials (<password>, <hostname>, <username>) ด้วย jq อัตโนมัติก่อนขึ้น GitLab
  • ส่งค่า Secret ตอนรันด้วย Docker -e KEY passthrough และรองรับการ Rollback ด้วย Git Tag (exported-* / imported-*)

2. Kubernetes Lab ก.ค.

ระบบคิวร้านอาหารเพื่อฝึกปฏิบัติการวางโครงสร้าง Container และ Kubernetes

  • ได้แอปพลิเคชันแบบ Microservices พร้อมระบบ JWT / OAuth2 Authentication
  • ตั้งค่า K8s Deployment, Service, HTTPRoute, ConfigMap, Secret และ Probes ครบถ้วน
  • ใช้งาน RBAC (Role/ClusterRole), NetworkPolicy Pod-to-Pod และ CronJob สำเร็จ

3. OpenShift Onboarding ส.ค. - ก.ย.

เว็บแพลตฟอร์ม Fullstack สำหรับรับคำขอและสร้างไฟล์ติดตั้งระบบขึ้น OpenShift

  • ได้ระบบ Fullstack (React + NestJS + PostgreSQL) ครบ 8 Tabs พร้อมแยกสิทธิ์ Dev/DevOps
  • เชื่อมต่อ Red Hat Keycloak SSO (BFF HttpOnly Cookie) และแยกข้อมูลรายทีม (WAS1/WAS2)
  • สร้าง Kustomize, ArgoCD, Kong, Kafka, Jenkinsfile อัตโนมัติพร้อม Real-time SSE Dashboard
  • ลดเวลา Build Container จากกว่า 7 นาที เหลือ 1.5 นาที ด้วย Unified Single-Container

4. FITs Budget System ก.ย. - ต.ค.

ระบบบริหารจัดการงบประมาณ IT ของธนาคาร (React + .NET 10 + PostgreSQL 16)

  • รองรับวงจรบริหารงบประมาณครบ 6 ขั้นตอน พร้อมรหัส BGID อัตโนมัติและแบ่งสัญญาข้ามปี
  • มีระบบ 4-Tier Waterfall Cut Simulator, Dual Ledger PO Booking และส่งออก Dynamics 365 GL
  • มีระบบ BOT SHA-256 Hash-Chained Audit Trail และบังคับใช้กฎ Maker-Checker
  • เชื่อมต่อ AAA OIDC SSO, ซิงค์โครงสร้างองค์กร HRMS และผ่านการทดสอบ E2E Playwright
